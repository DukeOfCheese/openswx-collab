# openswx-collab-protocol

The wire protocol shared by the [openswx](https://github.com/DukeOfCheese/openswx) collaboration server and
client: id-keyed operations on a CAD document (`diff`, `apply`, `targets`) and the WebSocket messages.
Depends on pydantic only.

Documentation, self-hosting guide and the protocol reference: https://github.com/DukeOfCheese/openswx-collab

Apache-2.0. openswx-collab is an independent open-source project, not affiliated with Dassault Systemes.
